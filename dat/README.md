### PlantCyc metabolic pathways
File: `plantcyc_pwy.tbl`

This file contains pathway–reaction associations derived from **PlantCyc version 17.0.0**, provided by the Plant Metabolic Network (PMN). The original database content was extracted and reformatted into a tabular representation for use in gapseq.

**License**: PlantCyc is maintained by the Plant Metabolic Network and is distributed under the _General Terms and Conditions of Open Database License for the Plant Metabolic Network Databases_. **Copyright and attribution**: © Carnegie Institution for Science and respective licensors. Original database authors and applicable copyright notices are acknowledged in the PlantCyc documentation. The original database license and attribution information should be consulted at [Plant Metabolic Network](https://plantcyc.org/?webform=license-agreement).

**Modifications**: Pathway identifiers and their associated reaction identifiers were extracted from PlantCyc 17.0.0 and converted into the plantcyc_pwy.tbl format. No additional database content is included.

### NCBI Taxonomy
File: `taxonomy_full.tsv.gz`

This file contains taxonomic information (IDs, names, and relations) derived from the [NCBI Taxonomy database](https://www.ncbi.nlm.nih.gov/datasets/taxonomy/). The data was retrieved 2026-10-14.

**License**: Public domain information on the National Library of Medicine (NLM) Web pages. See the [NCBI Website and Data Usage Policies](https://www.ncbi.nlm.nih.gov/home/about/policies/) for more information.
